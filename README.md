<h3>🏪 Superstore Sales Analysis</h3>

Normalised a flat 9,994-row retail CSV into a four-table relational schema (customers, products, orders, order_items) with foreign keys and indexes. Analysis found margin turns negative above a 20% discount — dropping to −77% at 40%+ — while average order quantity stayed flat, indicating discounts drove no incremental volume.

`SQL` `SQLite` `Window Functions`
